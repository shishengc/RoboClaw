💻 使用示例

【命令行示例】

# 从机器人获取图像
python scripts/generate_depth_and_3d_coords.py \
    --base-url http://localhost:8765 \
    --depth-model small

# 从本地文件读取
python scripts/generate_depth_and_3d_coords.py \
    --no-robot \
    --image-path image.jpg

# 使用 CPU 处理
python scripts/generate_depth_and_3d_coords.py \
    --device cpu \
    --image-path image.jpg

【Python 代码示例】

# 查询单个点的 3D 坐标
from scripts.generate_depth_and_3d_coords import PointTo3D, CameraIntrinsics
import numpy as np

depth_m = np.load("depth.npy")
intrinsics = CameraIntrinsics.from_fov(1280, 960, fov_degree=90)
converter = PointTo3D(intrinsics)

x, y, z = converter.pixel_to_3d(640, 480, depth_m[480, 640])
print(f"3D坐标: ({x:.3f}, {y:.3f}, {z:.3f})")

# 生成点云
point_cloud = converter.pixel_to_3d_array(depth_m)

# 目标检测
from scripts.advanced_grasping_examples import GraspingTargetDetector
detector = GraspingTargetDetector(intrinsics)
targets = detector.detect_by_brightness(rgb_image, depth_m)

✨ 特色功能

【交互式查询】
  在生成的深度图上点击任意像素，实时获取其三维坐标
  支持多点选择和结果保存

【目标检测】
  通过颜色或亮度自动检测图像中的目标物体
  计算每个目标的三维位置和置信度

【多帧融合】
  融合多个深度帧以提高精度
  提供深度不确定性估计

【灵活配置】
  预定义多种相机配置（RealSense、Azure Kinect 等）
  支持从视场角自动计算或手动指定内参

【完整可视化】
  彩色深度图显示
  检测结果可视化
  点云数据导出
